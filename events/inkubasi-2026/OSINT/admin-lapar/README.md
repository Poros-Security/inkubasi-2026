# Admin Lapar
> Category: OSINT
> Author: RFB   

## Description
Seorang admin pernah mengunjungi sebuah warung sederhana yang terkenal dan identik dengan hidangan hitam legendarisnya.

Ia sempat menyimpan catatan mengenai lokasi tempat tersebut di internet. Namun sayangnya halaman itu sudah dihapus dan tidak bisa diakses lagi.

Satu-satunya petunjuk yang tersisa hanyalah sebuah foto menu dari tempat tersebut yang tercoret sesuatu.

Jika kamu berhasil menemukan lokasi itu, ambillah tiga kata unik dari lokasi itu.

Setelah itu, rangkai tiga kata tersebut menggunakan format berikut:

```
https://bit.ly/word1_word2_word3
```
Namun berhati-hatilah…
Tidak semua halaman yang hilang benar-benar menghilang dari internet.

## PoC
```
Step
1. Cari di internet dan gunakan attachment untuk cari lokasi itu
2. setelah itu gunakan https://what3words.com/ untuk dapet 3 kata uniknya
3. setelah itu masukan format link di berikan
4. nah copy link pastebinnya di web archive org dan cari tanda biru dan kunjungi

```
